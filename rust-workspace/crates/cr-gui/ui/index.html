Sobre o ChronoKeep

ChronoKeep Manager

v0.1.2 — Solução Clean-Room de Preservação e Sincronização Steam Cloud

Salvaguardas de Integridade Ativas:

  • ✅ Isolamento de AppIDs de Sistema: 7, 760, 241100 e 241300 protegidos contra upload/sobrescrita indevida.
  • ✅ Monotonicidade de Change Number (CN): Saves locais nunca são sobrescritos se o CN da nuvem for inferior.
  • ✅ Prevenção de Corrupção por Token Recursivo: Higienização de tokens %WinMyDocuments% duplicados.
  • ✅ Controle de Concorrência RAII: Bloqueio estrito de downloads concorrentes simultâneos do mesmo AppID.
  • ✅ Acoplamento ao Ciclo de Vida Steam: O daemon encerra instantaneamente quando o processo steam.exe for finalizado.
Desenvolvido em Rust puro com interface moderna Windows 11 Fluent Design.
